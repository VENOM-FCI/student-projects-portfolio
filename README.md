# Student Projects Portfolio

Academic projects completed as part of the Information Systems degree at Assiut University. Both projects involved a five-student team; the notes below distinguish the work actually completed from the proposed system design.

## Projects

### 1. GYM AI — System Analysis & Project Planning
A proposed AI-assisted gym guidance system documented as a university systems-analysis and project-management report. The report covers the business need, proposed functions, four feasibility areas, work plan, Work Breakdown Structure (WBS), staffing plan, and risk assessment.

- **My role:** Team Leader & Final Document Designer
- **Team size:** 5 students
- **Deliverable:** Structured project-planning report
- **Scope note:** This was a system proposal and planning deliverable; it is not evidence that a working AI application was built or deployed.
- **Project documentation:** [GYM AI README](GYM-AI/README.md)

### 2. Airport Management Database — Microsoft Access
A university database assignment for airport-related records, documenting flights, passengers, employees, aircraft, baggage, gates, bookings, and airlines.

- **My role:** Primary Database Designer & Builder
- **Team size:** 5 students
- **My contribution:** Built the database; the other four teammates tested it, reported errors, and I corrected them.
- **Project documentation:** [Airport Database README](Airport-Management-Database/README.md)
- **Schema:** [Database schema notes](Airport-Management-Database/docs/database-schema.md) · [Relationship sketch](Airport-Management-Database/docs/relationships.md)

## Accuracy and privacy notes
- GYM AI is a proposed system. Technologies listed in its planning report are proposed options, not claims of personal implementation.
- The GYM AI source report contains inconsistent initial-cost figures. Do not present its financial calculations as independently validated.
- The original Microsoft Access database is not included in this repository because it contains fields for passport and contact details and its records need a privacy review. Only schema documentation is published.
- The database schema notes are an interpretation of object metadata; verify exact relationship settings in Access before treating them as a formal schema export.
