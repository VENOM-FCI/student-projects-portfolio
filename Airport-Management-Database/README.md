# Airport Management Database — Microsoft Access

**Project type:** University database assignment  
**Team size:** 5 students  
**My role:** Primary Database Designer & Builder

## Overview

This Microsoft Access database assignment organizes airport-related records in eight core tables: Flights, Passengers, Employees, Aircrafts, Baggage, Gates, Bookings, and Airlines.

## My contribution

I built the database end-to-end. The other four team members tested it to find errors, and I corrected issues they identified during the testing cycle.
