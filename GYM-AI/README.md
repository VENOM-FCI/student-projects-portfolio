# GYM AI — System Analysis & Project Planning

**Project type:** University systems-analysis and project-management assignment  
**Team size:** 5 students  
**My role:** Team Leader & Final Document Designer

## Project concept

GYM AI is a proposed system intended to improve gym-member satisfaction and retention through personalized fitness guidance. Proposed functions include:

- Personalized workout-plan generation
- Nutrition recommendations
- Member progress tracking
- Real-time exercise feedback

This repository documents the academic proposal and planning work. It does **not** claim that a working AI application was implemented or deployed.

## Work covered

The source report includes:

1. System request — business need, proposed functionality, expected value, and constraints.
2. Technical feasibility — proposed hardware, software, networking, and specialist roles.
3. Economic feasibility — estimated development/operating costs, expected benefits, cash flow, payback period, ROI, and NPV.
4. Organizational feasibility — user acceptance, management support, training, and expected organizational impact.
5. Operational feasibility — expected use in daily gym activities.
6. Work plan — task assignments, deliverables, dates, priorities, and estimated versus actual time for an example task.
7. Work Breakdown Structure (WBS) — design and development tasks, durations, dependencies, and status.
8. Staffing plan — proposed project roles and required skills.
9. Risk assessment — technical skill gap, hardware constraints, and data privacy risks, with mitigation ideas.

## My contribution

I led the five-person student team and designed the final report, bringing the system request, feasibility study, work plan, WBS, staffing plan, and risk assessment into one structured deliverable.
