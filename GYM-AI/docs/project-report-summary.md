# GYM AI — Project Report Summary

## Project purpose

The report proposes GYM AI, a system concept for improving gym-member satisfaction and retention through personalized fitness guidance.

## Proposed functions

- Generate personalized workout plans.
- Provide nutrition recommendations.
- Track user progress.
- Give real-time feedback during exercise.

## Feasibility analysis

The source report considers four areas:

- **Technical:** proposed server/client hardware, database systems, programming languages, AI frameworks, web/mobile access, APIs, connectivity, security, and required technical roles.
- **Economic:** one-time development cost estimates, annual operating cost estimates, forecast benefits, net cash flow, cash-flow table, payback period, ROI, and NPV.
- **Organizational:** user acceptance, management support, training, and expected organizational impact.
- **Operational:** expected ease of use, fit with daily activity, workflow efficiency, and reduction of human errors.

## Planning artifacts

The report includes a sample work plan, a task list/WBS with durations and dependencies, a staffing plan, and a risk assessment.

Risks mentioned include technical skill gaps, hardware constraints for real-time analysis, and data privacy. The report suggests training, pre-trained or optimized models, cloud processing for complex tasks, encryption, and secure protocols as possible mitigations.

## Team contribution

The project was completed by a five-student team. My role was team leader and final-document designer. My contribution was coordinating the group and designing/organizing the final report.

## Scope and accuracy limitations

This is a university **analysis and planning report** for a proposed system. It is not evidence that the AI system was built, tested with real gym users, or deployed.

The original report contains inconsistent initial-cost figures, including a malformed total in one table and a different amount in another section. The financial results should not be treated as validated until the team reconciles the source calculations.

Technologies mentioned in the plan (including Python, Node.js, React Native, MySQL, MongoDB, TensorFlow, PyTorch, and MediaPipe) are proposed options in the report, not necessarily technologies personally implemented by the team.
